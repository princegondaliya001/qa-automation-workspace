# Discord Dual Webhook System

Updated: 2026-05-28

## Overview

The commit watcher and test failure reporting system sends **two different message formats** to two separate Discord webhooks:

| Webhook | ID | Audience | Format |
|---------|-----|----------|--------|
| **Technical** | `1498991087539326987` | Developers / technical people | Full details: diff stats, selectors, API errors, reproduction steps |
| **Summary** | `1509429662529355958` | Managers / non-tech people | Clean summary: project name, status, brief what-changed, file count |

Both webhooks receive messages for **all events** — only the format differs.

---

## Events That Trigger Notifications

1. **Commit Watcher** — when a frontend repo changes and Maestro updates are processed
2. **Test Failures** — when Maestro automation or frontend UI tests fail

### Test Failure — Technical (Webhook 1)

```
**Test Failure Report: MaxStudio**

**Status:** FAILED
**Project:** MaxStudio
**Test Type:** Maestro Automation
**Error Type:** Element not found

**Description:**
Maestro flow maxstudio/video-tool.yaml step 7 — tapOn "Generate" timed out after 10s.

**Action Taken:** Auto-retry failed. Sub-agent dispatched to fix selector.
```

### Test Failure — Summary (Webhook 2)

## Scripts

- **`scripts/discord-summary.py`** — Main sender. Supports `send`, `preview`, `custom` commands.
- **`scripts/auto-process-simple-changes.py`** — Auto-processor that calls `send_entry_dual()` after simple changes.
- **`scripts/queue-auto-process.py`** — Queue manager (does not send directly; sub-agents use `discord-summary.py`).

## Environment

Configured in `state/maestro-discord.env`:

```bash
DISCORD_WEBHOOK_URL="https://discord.com/api/webhooks/1498991087539326987/..."
DISCORD_WEBHOOK_URLS="https://discord.com/api/webhooks/1498991087539326987/... https://discord.com/api/webhooks/1509429662529355958/..."
```

**Do not commit this file.** It contains secrets.

## Usage Examples

### Send dual-format for a queue entry
```bash
python3 scripts/discord-summary.py send <entry_id> "Optional result text"
```

### Preview both formats without sending
```bash
python3 scripts/discord-summary.py preview <entry_id> "Optional result text"
```

### Send custom message to both webhooks
```bash
python3 scripts/discord-summary.py custom "Hello both channels"
```

### Send custom message to only one webhook
```bash
python3 scripts/discord-summary.py custom "Tech-only message" --webhook=1
python3 scripts/discord-summary.py custom "Summary-only message" --webhook=2
```
